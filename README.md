A Python terminal program I made for creating and managing teams using Steam IDs.

## FEATURES
- Create a team and set an owner
- Add and remove team members
- View team information
- Search for players using their Steam ID
- Delete an existing team
- Maximum of 8 players per team
- Saves Steam IDs to `STEAMIDS.txt`

## FILES
- `main.py` – Main menu and team management functions.
- `STEAMIDS.txt` – Stores team owner and member IDs.

## REQUIREMENTS

- Python 3.x
- No additional libraries required.

## HOW TO USE

Run `main.py` and use the terminal menu to manage your team.
